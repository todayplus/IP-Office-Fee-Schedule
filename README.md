# 특허청(지식재산처) 수수료정보안내 – 반응형 정적 사이트

특허로(patent.go.kr) **"수수료정보안내(FeeMain01.do)"** 페이지의 콘텐츠를 PC/모바일에서
보기 쉽도록 반응형 HTML로 재구성한 정적 웹사이트입니다.

---

## 1. 프로젝트 목표

- 특허·실용신안·디자인·상표 관련 각종 **출원료, 등록료, 심판청구료, 국제출원 수수료,
  감면·면제 정보**를 표/목록 형태로 한 페이지에 정리
- PC와 모바일(스마트폰) 어디서든 표가 깨지지 않고 읽기 쉬운 **반응형 레이아웃** 제공
- **테마 전환(화이트/아이보리/블랙)**, **검색**, **즐겨찾기** 등 편의 기능 제공

---

## 2. 완료된 기능

### 콘텐츠
- 출원 관련 수수료 (출원료, 우선권주장/심사청구료/재심사청구료, 변경·분할·분리출원료, 보정료, 기타 수수료)
- 특허(등록)료 (설정등록료·연차등록료, 상표 설정등록/갱신, 기타 등록료)
- 심판관련 청구료(신청료) (심판청구료, 기타 청구료)
- 각종 서류의 등·초본 발급신청료 등 (증명신청료, 납부요령)
- PCT 국제출원 수수료 (국제출원료·조사료·송달료, 예상비용, 국제예비심사 수수료)
- 마드리드 의정서에 의한 국제출원수수료 등
- 헤이그협정에 따른 국제출원수수료 (국제출원료, 갱신료, 변경신청)
- 특허료·등록료·수수료의 감면 안내 (100%/85%/70%/50%/30% 감면 대상, 특별재난지역 감면, 평균감면·전자등록증 차감 제도)
- 납부방법
- 특허료 등의 징수규칙 원문 링크

### 기능(UI)
- **테마 전환 버튼**: 화이트 / 아이보리 / 블랙 3종, 선택값은 `localStorage`에 저장되어 재방문 시 유지
- **검색 버튼(검색창)**: 입력한 키워드가 포함된 섹션만 표시하고 본문 내 일치 텍스트를 하이라이트, 검색 결과 개수 표시, 결과 없음 안내
- **즐겨찾기 버튼**: 각 섹션(목차 항목) 제목 옆 별 아이콘으로 즐겨찾기 추가/삭제, 헤더의 즐겨찾기 버튼을 눌러 사이드 패널에서 목록 확인 및 바로가기 이동. `localStorage`에 저장되어 재방문 시 유지
- 좌측 고정 목차(TOC) – 스크롤 위치에 따라 현재 보고 있는 섹션 자동 하이라이트, 모바일에서는 햄버거 메뉴로 열고 닫는 슬라이드 패널
- 글자 크기 조절(A-/A+), 맨 위로 이동 버튼, 인쇄 버튼(브라우저 인쇄 다이얼로그, 인쇄 시 헤더/사이드바 등 UI 요소 자동 숨김)
- 모바일(390px)부터 데스크톱까지 반응형 대응, 표는 좌우 스크롤 가능

## 3. 페이지 구조 / 경로

정적 사이트이며 별도의 서버 라우트/파라미터가 없습니다.

| 경로 | 설명 |
|---|---|
| `index.html` | 메인(유일) 페이지. 앵커(`#sec-apply`, `#sec-register`, `#sec-trial`, `#sec-doc`, `#sec-pct`, `#sec-madrid`, `#sec-hague`, `#sec-discount`, `#sec-pay`, `#sec-rule`)로 각 섹션 이동 |
| `css/style.css` | 테마 변수 및 반응형 레이아웃 스타일 |
| `js/main.js` | 테마전환, 검색, 즐겨찾기, TOC 활성화, 글자크기, 맨위로, 인쇄 로직 |

## 4. 데이터 및 저장 방식

- 이 사이트는 백엔드/DB 없이 **정적 콘텐츠**로 구성되어 있으며, 수수료 데이터는
  `index.html`에 표(`<table>`)와 목록(`<ul>`) 형태로 직접 기술되어 있습니다.
  (원문 기준일: 2023.08.01, 일부 국제출원 수수료는 표기된 시행일 적용 / 원본 콘텐츠 최종
  업데이트일: 2026년 7월 16일 — 특허로 원문 기준)
- **사용자 설정 저장**: 브라우저 `localStorage`만 사용합니다.
  - `fee_theme` : 선택한 테마(white/ivory/black)
  - `fee_favorites` : 즐겨찾기한 섹션 id/제목 목록
  - `fee_font_scale` : 글자 크기 배율
- 별도의 테이블 API, 서버 데이터베이스는 사용하지 않습니다.

## 5. 아직 구현되지 않은 기능 / 알려진 제한

- 수수료 데이터는 스냅샷(정적 텍스트)이므로 **실시간 업데이트가 아닙니다.** 법령·환율 변동으로
  수수료가 바뀌면 이 페이지도 수동으로 갱신해야 합니다.
- 실제 수수료 계산기(예: 청구항 수, 지정상품 수를 입력하면 자동으로 합산 금액을 계산)는 없습니다.
- 다국어(영어 등) 버전은 없습니다.
- 검색은 페이지 내 클라이언트 검색(단순 텍스트 포함 여부)만 지원하며, 형태소 분석이나 유사어 검색은 지원하지 않습니다.
- 로그인/개인화 계정 기능은 없습니다(즐겨찾기는 브라우저 로컬 저장소 기반이라 기기/브라우저를 바꾸면 유지되지 않습니다).

## 6. 추천 추가 기능 (다음 단계 제안)

요청하신 테마 전환 / 검색 / 즐겨찾기 외에, 실제 사용성을 높이기 위해 아래 기능을 추가로 제안합니다.

1. **간단 수수료 계산기**
   - 예: "특허 전자출원, 청구항 5개, 국어" 처럼 옵션을 선택하면 출원료+심사청구료 합계를 자동 계산.
   - 감면 대상(개인/중소기업/중견기업 등) 체크박스를 추가해 감면 적용 후 예상 금액까지 보여주면 실무자에게 매우 유용합니다.
2. **감면 대상 자가진단(마법사형 Q&A)**
   - "당신은 개인입니까? 중소기업입니까? 나이가...?" 형태로 몇 가지 질문에 답하면 해당하는 감면율과 필요 증명서류를 안내.
3. **수수료 비교/북마크 공유 링크**
   - 즐겨찾기한 섹션 목록을 URL 쿼리스트링이나 공유 가능한 링크로 내보내어 동료에게 전달할 수 있게 함.
4. **최근 변경/업데이트 히스토리 배너**
   - "2026.1.1. 이후 시행" 등 시행일이 있는 항목을 모아 별도의 "다가오는 변경사항" 타임라인으로 보여주기.
5. **PDF/이미지로 저장(내보내기)**
   - 특정 섹션만 선택해 PDF로 다운로드하거나 이미지로 캡처해 저장할 수 있는 기능(클라이언트 라이브러리, 예: html2canvas + jsPDF 활용 가능).
6. **다크모드 자동 감지**
   - 시스템의 `prefers-color-scheme`을 감지해 최초 방문 시 기본 테마를 자동 제안(사용자가 직접 바꾸면 그 값을 우선).
7. **용어 설명 툴팁**
   - "가산료", "설정등록료", "일부심사" 등 전문 용어에 마우스오버/탭 시 간단한 설명이 나오는 툴팁 추가.
8. **접근성 강화**
   - 표에 대한 스크린리더용 요약, 키보드 전용 사용자를 위한 포커스 표시 강화, 명도 대비 자동 점검.
9. **최신 데이터 자동 동기화 안내**
   - 정적 사이트 특성상 실시간 크롤링은 어렵지만, "최종 확인일" 배지와 "원문 새 창에서 확인" 버튼을 각 표 상단에 추가해 신뢰도를 높일 수 있습니다.
10. **다국어 지원(영어)**
    - 외국 출원인/대리인을 위한 영문 요약 버전 제공.

## 7. 배포

이 프로젝트는 정적 파일(HTML/CSS/JS)만으로 구성되어 있어 GitHub Pages, Netlify, Vercel 등
어떤 정적 호스팅에도 그대로 올릴 수 있습니다. 별도의 서버/빌드 과정이 필요 없습니다.

- 이 편집기에서 배포하려면 **Publish 탭**에서 배포 버튼을 눌러주세요. Publish 탭이 배포를
  자동으로 처리하고 배포된 사이트 URL을 제공합니다.
- GitHub에 별도로 올려 GitHub Pages로 배포하는 경우: 저장소 루트에 `index.html`, `css/`,
  `js/` 폴더가 그대로 있으면 되며, 저장소 설정의 Pages 옵션에서 브랜치/루트 디렉터리를
  지정하면 됩니다.
